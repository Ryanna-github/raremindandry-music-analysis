# 人声细分与组合导出

## 操作

1. 在三维总览上方点击「拆分人声 → 主唱 / 合声 / 观众声」，或轨道树中人声右侧「拆分」。展开后是 8 条展示轨：3 个全片人声子轨加 5 个配乐轨；总人声不重复参与混听。网页记住该音频的展开状态。
2. 点击轨名编辑当前轨的处理方式。主唱默认「连续保留」，合声默认「保守清理」，观众声暂只有候选版；每轨保存各自的处理选择。
3. 点击波形、图中标签或轨道旁勾选按钮选择组合。不选的轨道保留透明轮廓及可恢复标签，并停止音频输出。轨名用于编辑，不用于静音。
4. 在「导出当前勾选组合」选择 WAV（24-bit PCM）或 MP3（320 kbps），范围可选择全片、自定义时间段或当前 A/B 范围。自定义时填写开始和结束，例如 `01:08.250`–`01:15.750`，也可用小数秒 `68.25`–`75.75`，支持时:分:秒。页面显示片段时长，至少 0.05 秒；时间无效、超出全片或结束不晚于开始时不可导出。
5. 自定义区域「取播放点」可将当前原视频播放位置填入开始或结束，「复制当前 A/B」可作为编辑起点。修改导出时间不会移动播放点或改变 A/B 循环，切换编辑音轨也保留自定义输入。点击导出，完成后分别下载组合音频和 JSON 清单，文件名包含该片段的起止时间。

导出按点击时的组合及时间快照执行，之后改变勾选、处理方式或起止时间不修改在途任务。全静音及原曲参考 / 处理对照模式不能提交组合导出。暂停与导出相互独立。

## 音频策略

- 原速 1.0、44.1 kHz、双声道；即使试听调慢，也不生成慢速导出。
- 优先使用已归档无损分轨；根据 `listening_gain_db` 和 `archive_scale` 恢复各轨试听电平。缺少校准元数据时使用试听 MP3，避免以不同归档电平混合。WAV 容器不会恢复 MP3 已丢失的细节。
- 与网页混听相同，固定每轨增益为 `0.85 / 当前展示轨数`（基础 6 条、展开 8 条），取消轨道不自动放大剩余轨道。不另外加限制器、归一化、修音或合成补音。
- 依据原视频绝对时间对齐；非全片轨只在实际覆盖时间内出现，其余位置补静音。
- 清单记录选中音轨、处理版本、时间范围、增益、源文件 SHA-256 及输出参数，便于复现。

## 本地性与限制

子声部需先在本机生成，网页按钮展开已有分离缓存，不运行模型。观众声为候选，不能据此确认存在人群；主唱与合声可能含对方尾音、残响和串音。组合不保证精确复原原曲混音。仓库只提供代码，不包含用户的歌曲或生成音轨。

需要以 `work/separator-env/bin/python work/demucs-detailed/serve_demo.py` 启动服务；直接双击 HTML 或用普通静态服务器只能试听。所有新导出仅保存在本机 `outputs/instrument_demo/exports/<id>/`；每次使用唯一目录，不覆盖原音轨。一次运行一个任务，可另排队一个任务。

## 导出文件

完成后点击「下载组合 WAV / MP3」或「下载组合清单 JSON」。结果不会自动触发下载，文件默认保存在本机 `outputs/instrument_demo/exports/<id>/`。源音频、组合清单和导出文件均不随源码上传到 GitHub。
